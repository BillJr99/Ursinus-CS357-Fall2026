# Activity Index

Every activity deck in this course, 106 of them, in one place.

The course schedule now lists at most three optional links per session, so that the required reading for any given day is unmistakable. Everything else lives here. Nothing on this page is required unless a session or an assignment says so — this is a library, not a backlog.

**How to use it.** If a lab direction or a class session names a deck, follow that link. Otherwise browse by theme when you want to go deeper on something that caught your attention, or when you are choosing a project direction and want to know what is possible.
