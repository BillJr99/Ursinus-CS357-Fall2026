## 1) What Are Agentic Systems?

- **Traditional LLMs**: reactive, respond to prompts statelessly.  
- **Agentic systems**: integrate LLMs with:
  - **Perception**: ingest text, images, audio, or structured data.  
  - **Reasoning**: plan sequences of actions or reasoning steps.  
  - **Action**: interact with tools, APIs, environments.  

**Example:** An AI tutoring agent that:  
1. Reads a math problem (perception).  
2. Plans a solution strategy step-by-step (reasoning).  
3. Uses a math solver or graphing tool to check work (action).  

---

## 2) The Agent Loop

Generalized **sense–think–act cycle**:

```
while not done:
    observation = perceive(environment)
    reasoning = LLM(observation, memory)
    action = decide(reasoning)
    environment = execute(action)
```

- Agents are not just **stateless chatbots**; they maintain **state** and **goals**.  
- Often integrated with retrieval (RAG) or tools (e.g., search, calculators, databases).  

---

## 3) Planning in Agentic Systems

Agents can be viewed through the lens of **sequential decision making**:

- State $s_t$: representation of current knowledge or environment.  
- Action $a_t$: generated by the LLM or planner.  
- Transition $s_{t+1} = f(s_t, a_t)$.  

In reinforcement learning terms, agents aim to **maximize expected reward**:

$$
J(\theta) = \mathbb{E}\left[ \sum_{t=0}^T \gamma^t r(s_t, a_t) \right].
$$

---

## 4) Tools and APIs as Extensions of Cognition

- **Tool use**: Agents can call external functions (search engines, databases, code execution, APIs).  
- This extends the model beyond its training data.  
- Requires mechanisms for:  
  - *When* to call a tool.  
  - *How* to format queries.  
  - *How* to integrate outputs into reasoning.  

**Example (pseudo-code):**

```python
if "calculate" in reasoning:
    action = call_python(code)
if "search" in reasoning:
    action = call_web(query)
```

## 5) Implementing a Basic LLM Agent (Python)

```python
from openai import OpenAI
client = OpenAI()

# Simple tool: a calculator
def calculator(expr: str):
    try:
        return str(eval(expr))
    except Exception as e:
        return f"Error: {e}"

# Agent loop
def run_agent(query):
    memory = []
    for step in range(3):
        messages = [{"role": "system", "content": "You are a helpful assistant."}]
        messages += memory
        messages.append({"role": "user", "content": query})

        resp = client.chat.completions.create(
            model="gpt-4o-mini",
            messages=messages
        )

        msg = resp.choices[0].message.content
        print(f"LLM step {step}: {msg}\n")

        if "[calc]" in msg:
            expr = msg.split("[calc]")[-1].strip()
            result = calculator(expr)
            memory.append({"role": "assistant", "content": f"Result: {result}"})
        else:
            return msg

    return msg

# Example
print(run_agent("What is (12+7)*3? Use [calc] <expr> if you need to calculate."))
```

## 6) Memory & Reflection

- **Short-term memory**: stored in the context window.  
- **Long-term memory**: persistent store (vector DB, logs).  
- **Reflection**: model reviews its own past outputs, detects errors, and retries.

## 7) Agents vs. Other Generative Models

- **VAEs**: structured latent space, focus on representation learning.  
- **GANs**: adversarial training, good for realistic outputs but unstable.  
- **Diffusion models**: powerful but expensive; good at fine-grained generation.  
- **Agentic systems**: not just generators — they **use tools, plan, and adapt**.  

---

## 8) Ethical & Societal Considerations

- **Autonomy & accountability**: who is responsible for an agent’s actions?  
- **Prompt injection**: malicious users may trick agents into unsafe behavior.  
- **Over-trust**: users may attribute human-like authority to personas.  
- **Governance**: need guardrails, transparency, and oversight.  

**Reflection Prompt:**
